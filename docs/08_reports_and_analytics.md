## 5. Modal Blueprint: `+ Build Custom Report`
- **Report Name & Description:** Custom Title, Target Audience (Board / HODs).
- **Data Source Module:** Dropdown (`General Ledger`, `Invoices`, `Inventory`, `Payroll`, `Projects`).
- **Metrics Selection (Columns):** Checkbox matrix of available fields (Date, Customer, Amount, VAT, Margin).
- **Filters & Grouping:** Group by Month, Customer, Division, Cost Center.
- **Output Preferences:** Chart Type (Bar / Line / Table), Export Format.
- **Buttons:** `Save & Run Query`, `Schedule Monthly Email`, `Cancel`.
